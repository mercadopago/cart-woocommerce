run-all-report.sh

Executa a suíte E2E completa (7 países × 2 checkouts) e gera um relatório consolidado em e2e/results/report.md.

14 combinações sem retries por padrão relatório markdown PSE (MCO)

Opções

FlagDescriçãoPadrão
--site SITE Roda apenas o país informado todos
--checkout MODE Roda apenas o modo de checkout (classic ou blocks) ambos
--with-retries Habilita retries do playwright.config.js (2x por falha).
Sem esta flag cada teste roda apenas 1 vez — mais rápido, mais direto.		 sem retries
--release Atalho para regressão oficial de release: roda a matriz completa com PSE via run-pse.sh e retries. Equivale a --with-pse + --with-retries. —
--with-pse Habilita o PSE (MCO) via mu-plugin temporário que intercepta woocommerce_get_checkout_order_received_url e retorna um domínio HTTPS válido para o callback_url (sem alterar home_url() global). Sem esta flag PSE falha em localhost e a causa real aparece no relatório. PSE desabilitado
--no-report Desabilita a geração do relatório HTML consolidado e não abre o browser. Útil para runs rápidos ou CI. relatório gerado
--rerun-failed Re-roda APENAS os specs que falharam na run completa anterior, por combinação, e gera o relatório consolidado. Lê os JSONs de results/ (rode a matriz completa antes). Aceita os mesmos filtros (--site, --checkout, --with-retries, etc.); combinações sem falha anterior são puladas. —
--prod Roda em ambiente de produção (test_mode=no), usando MP_ACCESS_TOKEN_PROD_<SITE> / MP_PUBLIC_KEY_PROD_<SITE>. Equivale a MP_ENV=prod. test (sandbox)
--debug Abre o Playwright Inspector para UMA combinação (requer --site e --checkout). Com --rerun-failed, só os que falharam. —
--menu, -m Modo interativo: pergunta país, checkout, retries, relatório, ambiente e PSE. —
--clean Apaga tudo em e2e/results/ (JSONs, logs, blobs, report.md e histórico) e sai sem rodar testes. —
--help, -h Exibe o help no terminal. —
--help --interactive Abre o help em página HTML no browser. —

Sem retries vs. com retries

Por padrão o script roda sem retries — cada teste executa apenas uma vez, dando feedback imediato sem esperar tentativas extras. Use --with-retries para regressões oficiais onde falhas de sandbox precisam ser absorvidas.

ModoTentativas por falhaTempo extraQuando usar
Padrão (sem retries) 10Debug, smoke rápido, CI com falhas reais
--with-retries 3 (1 + 2 retries)+30-60s por falhaRegressão oficial de release

Exemplos

Matriz completa sem retries (padrão)

bash e2e/run-all-report.sh

Só Brasil classic — debug rápido

bash e2e/run-all-report.sh --site MLB --checkout classic

Matriz completa com retries — regressão oficial

bash e2e/run-all-report.sh --with-retries

Brasil em produção (test users / cartões de teste)

bash e2e/run-all-report.sh --site MLB --prod

Matriz completa + PSE (MCO)

bash e2e/run-all-report.sh --with-pse --with-retries

Investigando falhas

Após um run com falhas, use o Playwright UI para inspecionar teste a teste:

Todos os que falharam — recomendado

SITE=MLB CHECKOUT=blocks npx playwright test tests/mlb/ --last-failed --ui

Usa o cache do último run — abre o UI já filtrado pelos testes que falharam.

Por arquivo

SITE=MLB CHECKOUT=blocks npx playwright test tests/mlb/chocredits/ --ui
SITE=MLB CHECKOUT=blocks npx playwright test tests/mlb/chocustom/checkout_validation_gate.spec.js --ui
SITE=MLB CHECKOUT=blocks npx playwright test tests/mlb/chopro/modal/ --ui
SITE=MLB CHECKOUT=blocks npx playwright test tests/mlb/chopro/redirect/ --ui

Teste específico por linha

SITE=MLB CHECKOUT=blocks npx playwright test tests/mlb/chocustom/checkout_validation_gate.spec.js:33 --ui

Substitua o número da linha pelo número que aparece no relatório de falhas.
